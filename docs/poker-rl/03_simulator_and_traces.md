# 03. Быстрый симулятор и трейсы

## Результат

Среда запускает множество раздач без UI, возвращает batched observations и сохраняет достаточные данные для обучения и воспроизведения.

## Действия

1. Определить API среды: `reset`, `step`, `legal_action_mask`, `terminal`, `rewards`.
2. Реализовать параллельный запуск нескольких независимых столов.
3. Разделить полное состояние среды и наблюдение игрока: политика не имеет доступа к чужим закрытым картам.
4. Сохранять replay каждой выбранной раздачи и компактный training trace для каждой точки решения.
5. Замерить скорость раздач в секунду; оптимизировать только профилированные горячие места.

## Формат trace

Каждая запись перед действием должна включать:

```text
hand_id, seed, hero_seat, street, observation,
legal_action_mask, selected_action, action_log,
pot, stacks, active_players, terminal_pnl_bb,
equity_snapshot_reference
```

Полное скрытое состояние разрешено хранить только в обучающем артефакте, который не передаётся модели или UI до вскрытия.

## Производительность

Сначала нужна корректность и профилирование. Затем можно батчить оценку сетей, векторизовать среду и переносить evaluator/ставки в скомпилированный код. UI никогда не участвует в контуре обучения.

## Критерий приёмки

Один процесс может воспроизводимо сгенерировать большой набор раздач; trace позволяет восстановить ход раздачи и вход агента в каждой точке решения.
