# 04. Базовые оппоненты

## Результат

Набор детерминированных и стохастических ботов для тестов, первичного сбора данных и измерения прогресса агента.

## Реализовать

- `RandomBot`: случайно выбирает легальное действие.
- `TightBot`: узкий префлоп-диапазон, мало блефов.
- `AggroBot`: высокий приоритет рейзов и давления.
- `CallingStationBot`: редко делает fold после входа в банк.
- `RuleBot`: использует приближённую силу руки, pot odds, позицию и простые пороги.

## Действия

1. Выделить общий интерфейс бота: на входе observation и маска, на выходе легальное действие.
2. Задать seed для воспроизводимости стохастических ботов.
3. Записать характерные статистики каждого бота: VPIP, PFR, 3-bet, fold-to-raise, aggression factor.
4. Запустить турнир с ротацией позиций и убедиться, что боты ведут себя ожидаемо.

## Критерий приёмки

RuleBot стабильно превосходит RandomBot на достаточном числе рук, а все боты совершают только легальные действия.
