# План создания 5-max RL-агента для No-Limit Texas Hold'em

Цель проекта — обучаемый агент для cash-game 5-max No-Limit Texas Hold'em с наблюдаемым веб-столом. Агент играет в self-play, а интерфейс показывает его действия, ожидаемый результат и оценку силы руки (`equity`).

## Зафиксированные решения

- 5 игроков, равные стартовые стеки `100 BB`, блайнды `0.5 / 1 BB`.
- Полные правила Hold'em: префлоп, флоп, тёрн, ривер, all-in, side pots, split pots.
- Ограниченное пространство рейзов: `min-raise`, `1/3 pot`, `1/2 pot`, `3/4 pot`, `pot`, `1.5 pot`, `all-in`.
- Одна сеть и общие веса для всех позиций; позиция входит во входные признаки.
- Обучение: curriculum (heads-up → 3-max → 5-max) и league self-play.
- Основной алгоритм первой версии: PPO/GAE; Deep CFR/NFSP — отдельный исследовательский этап после стабилизации среды.
- Дополнительная equity-head возвращает `P(win)`, `P(tie)`, `P(loss)` и отображаемое значение `P(win) + 0.5 × P(tie)`.
