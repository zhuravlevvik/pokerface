# 07. Equity-head и тренировочные метки

## Результат

Вспомогательная голова учится предсказывать исход виртуального вскрытия по
безопасному наблюдению игрока. Текущий протокол метки использует фактически
сданные скрытые карты активных оппонентов и случайные будущие карты доски.
Это `fixed_deal_virtual_showdown_v1`, а не range equity по публичной истории.

## Семантика

`Equity` — не вероятность фактической победы в текущей раздаче и не value.
Голова выдаёт категориальное распределение `[win, tie, loss]` виртуального
вскрытия. В heads-up из него можно получить ожидаемую долю банка:

```text
equity = P(win) + 0.5 × P(tie)
```

В multiway ничья может делить банк между тремя и более игроками, поэтому
эта формула там неверна. До появления отдельной expected-share метки
калибровка и promotion gate скаляра выполняются только в heads-up.

## Формирование target

1. Перед важным действием сохранить snapshot состояния и активных игроков.
2. Внутри training environment использовать скрытые карты активных игроков только для построения метки.
3. Для неизвестных общих карт выполнить K случайных досдач (`K=8–32` на старте).
4. Для каждой досдачи определить `win`, `tie` или `loss` героя.
5. Создать мягкую метку `q=[wins/K, ties/K, losses/K]`.
6. На ривере использовать точный исход; на флопе/тёрне перечислять все
   runout-комбинации, если заданный `K` покрывает их число.
7. Разделять train/holdout по seed всей раздачи, а не по отдельным решениям;
   holdout строить с большим `K` и хранить `K/exact/protocol` рядом с меткой.

Не использовать как target фактическое завершение раздачи: fold и блеф делают эту метку некорректной для оценки силы руки.

## Loss и контроль качества

Использовать soft-target cross-entropy:

```text
L_equity = -sum(q_i * log(p_i))
```

Проверять multiclass logloss, Brier score и heads-up calibration error по
street × числу игроков × числу активных оппонентов. Сравнивать Brier с
эмпирическим prior, посчитанным только на train split.

## Критерий приёмки

На синтетических состояниях с очевидной силой руки equity-head ранжирует натс выше слабой руки; calibration-отчёт строится по holdout-раздачам.
