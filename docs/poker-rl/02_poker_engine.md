# 02. Движок покера и тесты корректности

## Результат

Детерминированный по seed движок, который проводит раздачу по правилам и не зависит от обучения или UI.

## Структура модулей

```text
poker/
  cards.py          # карты, колода и раздача
  evaluator.py      # комбинации и сравнение рук
  betting.py        # ставки, рейзы, all-in, side pots
  rules.py          # порядок действий и легальность ходов
  game_state.py     # полное состояние текущей раздачи
  observation.py    # проекция состояния для конкретного игрока
  environment.py    # интерфейс среды обучения
```

## Действия

1. Реализовать карту, колоду и воспроизводимую тасовку по seed.
2. Реализовать оценщик всех комбинаций и сравнение семикарточных рук.
3. Реализовать состояние ставок: текущая ставка, размер последнего полного рейза, вложения игрока на улице и в раздаче.
4. Реализовать переходы улиц, сдвиг позиции и раннее окончание раздачи, когда остался один игрок.
5. Реализовать all-in и side pots так, чтобы сумма фишек всегда сохранялась.
6. Добавить сериализацию раздачи в replay-формат.

## Обязательные тесты

- все классы покерных комбинаций и их тай-брейки;
- общая комбинация на борде, делёж банка и округление фишек;
- min-raise и право на повторный рейз;
- all-in до и после рейза;
- два и более side pots;
- корректный порядок действий на всех улицах;
- отсутствие повторяющихся карт;
- сохранение общего числа фишек;
- идентичный replay при одинаковом seed и действиях.

## Критерий приёмки

Набор unit- и scenario-тестов проходит; на каждой раздаче выполняются инварианты колоды, ставок и общего баланса фишек.
