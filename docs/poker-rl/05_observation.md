# 05. Наблюдение агента

## Результат

Версионированная схема входов сети, доступная каждому игроку без утечки закрытой информации.

## Входные группы

```text
Карты: две карты героя, публичный борд, улица.
Герой: позиция, стек, вложения, текущая цена call, min-raise.
Стол: банк, активные игроки, общая структура ставок.
Игроки: позиция, стек в BB, ставка на улице, all-in/fold-маска, последняя акция.
История: улица, позиция, тип действия и нормализованный размер каждого действия.
```

Денежные признаки нормализуются в BB и относительно банка. Число игроков не кодируется жёсткими индексами: каждый игрок — элемент набора с mask, поэтому одна модель применима к heads-up, 3-max и 5-max.

## Действия

1. Описать typed-схему observation и её версию.
2. Написать преобразователь полного GameState в observation для заданного места.
3. Добавить тест: перестановка карт противника не меняет observation героя.
4. Добавить тест: маска запрещает действия, недопустимые в текущем состоянии.
5. Логировать статистики признаков для контроля нормализации.

## Критерий приёмки

Схема одинакова в train и inference; тесты подтверждают отсутствие доступа к закрытым картам соперников и будущему борду.
