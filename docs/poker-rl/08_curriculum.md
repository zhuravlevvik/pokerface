# 08. Учебная программа

## Результат

Стабильный перенос навыков от простого покера к 5-max без обучения с нуля на самой сложной среде.

## Этапы

```text
A. Heads-up: равные стеки, мало сайзингов.
B. Heads-up: полный стартовый набор сайзингов.
C. 3-max: та же сеть, те же базовые правила.
D. 5-max: равные стеки и фиксированный action space.
E. 5-max: расширение стека и сайзингов при доказанной стабильности.
```

## Действия

1. Предобучить card/backbone/equity части на раздачах rule-based и случайных политик.
2. Запустить self-play на heads-up до превышения базлайнов и приемлемой калибровки equity.
3. Сохранить checkpoint и продолжить обучение на 3-max с уменьшенным learning rate.
4. Перейти к 5-max только после устойчивого выигрыша на предыдущем этапе.
5. При каждом переходе сохранять контрольный набор предыдущего режима, чтобы отслеживать catastrophic forgetting.

## Критерий приёмки

Каждый переход подтверждён оценкой против фиксированных ботов и предыдущих checkpoint’ов; перенос инициализации выигрывает у обучения с нуля при одинаковом бюджете шагов.
